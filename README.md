Этот проект использует искусственный интеллект для разделения клиентов банка на группы (кластеры) на основе их финансового поведения. 
Мы анализируем баланс на счету, покупки, снятие наличных и кредитный лимит, чтобы понять, как ведут себя разные типы пользователей.

1. Supervised (С учителем)
Это когда у тебя есть шпаргалка с ответами.
Пример: Ты показываешь роботу фото и говоришь: «Это кот», «Это собака».
Результат: Робот запоминает признаки и потом сам узнает их на новых фото.
Суть: Учеба по принципу «Повторяй за мной».

2. Unsupervised (Без учителя)
Это когда ответов нет, робот брошен на произвол судьбы.
Пример: Ты даешь роботу кучу фото животных и молчишь.
Результат: Робот сам замечает:Так, у этих уши острые, а у этих висячие типа и раскладывает их на две разные кучки (Кластер 0 и Кластер 1).
Суть: Робот сам ищет сходства и делит на группы.

Чтобы скачать и запустить проект:
1. git clone https://github.com/Limbovsk1/Credit-Card-Dataset-for-Clustering.git
cd Credit-Card-Dataset-for-Clustering
2. pip install pandas scikit-learn joblib matplotlib streamlit
3. python train.py
4. streamlit run app.py
C 3 пункта по 4 вам нужно это прописать в терминале
